# Team formation and responsibility plan

The course brief requires a two-member team approved by the instructor, with both members contributing to database and application development.

| Role | Member | Database contribution | Application contribution |
|---|---|---|---|
| Member 1 | To be filled by the team | PostgreSQL schema, constraints, queries, transactions, tests | Next.js API integration, validation |
| Member 2 | To be filled by the team | SLA functions/triggers, query tuning, test data | UI, authentication/authorization, Qdrant integration |

## Evidence to complete before submission
- [ ] Enter both official member names and SRNs.
- [ ] Confirm instructor approval.
- [ ] Maintain individual GitHub commits under each member's own account.
- [ ] Record a short contribution log for each milestone.

Names and approval details are intentionally left blank rather than fabricated. Both members should review and explain the database and application layers during the demonstration.
